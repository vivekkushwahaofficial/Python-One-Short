# Python — Quick Overview

## What is Python?

Python is a high-level, general-purpose programming language known for its simple and readable syntax.

Common uses:

- Backend development
- Automation
- Data engineering
- AI/ML
- Testing
- DevOps

## How Python Works

Basic flow:

    Python Source Code (.py)
            ↓
        Bytecode
            ↓
    Python Runtime / PVM
            ↓
          Output

In CPython, source code is compiled into bytecode, and the Python runtime executes that bytecode.

## Key Features

- High-level
- Dynamically typed
- Strongly typed
- Object-oriented
- Cross-platform
- Readable syntax
- Large standard library

## Python vs Java

| Java                   | Python                     |
| ---------------------- | -------------------------- |
| Statically typed       | Dynamically typed          |
| `{}` define blocks     | Indentation defines blocks |
| `System.out.println()` | `print()`                  |
| `Scanner`              | `input()`                  |
| `ArrayList`            | `list`                     |
| `HashMap`              | `dict`                     |
| `HashSet`              | `set`                      |
| `this`                 | `self`                     |
| JVM                    | Python Runtime             |

## Variables

Python does not require explicit type declarations.

## Quick Revision

- `print()` → output
- `input()` → user input
- `def` → define a function
- Python uses indentation for blocks
- Python is dynamically typed
- `list` → ordered, mutable collection
- `tuple` → ordered, immutable collection
- `set` → unique elements
- `dict` → key-value pairs

### Python Execution

**`.py` source → bytecode → Python runtime → execution → output**
